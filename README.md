# 公开版课表空白模板

一个完全离线、可模块化维护的课表看板模板。默认没有课程，不包含真实学校、班级、教师或教室资料。

## 使用

打开 index.html，或只复制 outputs/课表空白模板_离线Demo.html 到另一台设备。
首页、进度看板、经典课表、学期总览、沉浸模式和五种进度可视化均可用。
在沉浸模式里设置一个自定义状态和未来结束时间，即可演示动态进度，不必填写课程。

## 维护

- src/data/schedule.js：填写学期、课程、排课和学校停补课例外。
- src/data/times.js：填写每节课的上、下课时间及午间、课间规则。
- src/data/holidays.js：维护国务院节假日、调休日期和官方来源。
- src/data/calendar.js：自动汇总上述数据；通常不需编辑。
- docs/MAINTENANCE.md：填写与发布说明。
- node scripts/build-offline.cjs：重新生成单文件。

此项目仅建立本地 Git，未配置远程仓库，也未发布到互联网。
浏览器自定义状态保存在本机，不写入HTML。公开发布前请重新核查自行填写的数据。
