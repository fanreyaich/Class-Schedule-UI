# 课表空白模板 · 离线 Demo

一个可在电脑和手机浏览器直接打开的离线课表看板。它不需要服务器、账号或网络连接；默认不含学校、班级、课程、教师、教室或个人日历信息。

课程数据、上课时间和法定节假日彼此独立，适合复制后维护成自己的课表。

## 快速开始

### 只想使用模板

1. 下载或复制 [`outputs/课表空白模板_离线Demo.html`](outputs/课表空白模板_离线Demo.html)。
2. 双击用浏览器打开；在手机上将该文件传到手机后，用浏览器或文件管理器打开即可。
3. 初次打开是空白课表。沉浸模式可设置一个自定义状态和结束时间，预览计时与进度效果。

这个单文件可以离线使用。仅当点击“查看公开来源”时，浏览器才会访问政府网站。

### 想填写自己的课表

1. 用编辑器打开项目文件夹。
2. 在 `src/data/schedule.js` 填入开学周一、课程和排课。
3. 按学校作息修改 `src/data/times.js`。
4. 如有需要，更新 `src/data/holidays.js` 中的法定假日与调休日期。
5. 直接打开 `index.html` 查看效果。
6. 安装 Node.js 后运行：

   ```bash
   node scripts/build-offline.cjs
   ```

   重新生成可单独发送的 `outputs/课表空白模板_离线Demo.html`。

详细字段与补课、停课写法见 [`docs/MAINTENANCE.md`](docs/MAINTENANCE.md)。

## 页面一览

| 页面 | 用途 |
| --- | --- |
| 首页 | 当前日期、教学周、时间段与下一节课入口 |
| 进度看板 | 整体、课程、周次与学期进度；今日安排、空闲时间与节假日 |
| 经典课表 | 周一至周日的传统节次课表 |
| 学期总览 | 覆盖全部教学周的长课表 |
| 沉浸模式 | 当前上课、休息、午间、节假日或自定义状态的计时页面 |
| 进度全屏 | 无时钟的沉浸式进度展示，含五种可切换视觉效果 |

## 可维护数据

| 文件 | 维护内容 |
| --- | --- |
| [`src/data/schedule.js`](src/data/schedule.js) | 学期、课程、排课、停课与补课例外 |
| [`src/data/times.js`](src/data/times.js) | 每节课的开始/结束时间、午间和课间规则 |
| [`src/data/holidays.js`](src/data/holidays.js) | 法定节假日、调休工作日与官方通知来源 |
| `src/data/calendar.js` | 自动汇总前三项，通常不需要修改 |

模板默认使用 8 节、每节 45 分钟的通用示例作息；这不代表任何学校。`holidays.js` 目前载入的是国务院办公厅公布的 2026 年节假日安排，学校停补课仍应以本校校历为准。

## 项目结构

```text
src/data/       三类可维护数据
src/            页面逻辑、样式与进度视觉效果
docs/           维护指南
outputs/        可单独分享的离线 HTML
scripts/        离线打包与浏览器验收脚本
```

## 隐私与发布前检查

- 浏览器中的自定义状态只保存在当前设备，不会写进 HTML，也不会同步。
- 提交或公开前，请检查 `courses`、`rules`、`cancelledDates` 和 `extraLessons` 是否含有不应公开的课程、人员、地点或校历内容。
- 不要把截图、浏览器配置、密钥、原始课表或个人路径加入仓库。

## 本地验证

修改后可运行：

```bash
node scripts/build-offline.cjs
node scripts/verify-browser.cjs
```

第二条命令用于本机浏览器验收，需要预先具备 Playwright 和 Edge 环境；不能运行时不影响正常打开和打包。
